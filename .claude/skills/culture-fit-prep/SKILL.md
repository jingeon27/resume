# 컬처핏 인터뷰 준비

컬처핏 준비 요청이 오면 이 절차를 따른다. 각 단계의 규칙은 실전에서 실패한 뒤 추가된 것이다 — 건너뛰지 않는다.

## 1. 재료 수집

- 공고 전문에서 **컬처 키워드**를 뽑는다 (예: 챌린저스 "이렇게까지 해야 해?", 레브잇 "Vision aligned Problem Solver"). 답변 어딘가에서 이 키워드를 정면으로 받는 문항을 하나 만든다.
- **사전 제출물을 전부 다시 읽는다** — 지원서, 사전 설문, 이력서. 면접관은 그걸 보고 들어온다.
  - ⚠️ 챌린저스에서 사전 설문의 "가고 싶은 회사: 메타"가 면접 서사("제품·비즈니스에 가까운 곳")와 충돌해 준비 안 된 인상을 남겼다. **이미 제출한 답과 면접 답의 정합성 점검은 선택이 아니라 필수다.** 어긋난 게 있으면 면접에서 먼저 잇는 문장을 준비한다.
- 제품을 실제로 써 본다. 좋았던 지점 1개, 아쉬운 지점 1개("이런 트레이드오프가 있었을 것 같다" 톤)를 채운다. 안 쓰고 가면 "왜 우리 회사인가"의 진정성이 통째로 무너진다.

## 2. 답변 문서 작성

기준 문서는 `챌린저스 온라인 컬처 인터뷰 답변 v3.md`. 새 회사는 이 문서를 복사해 회사별로 만들고, 다음을 교체한다.

- 왜 이 회사인가 (공고 키워드 + 사업 숫자 인용 — 공고를 읽었다는 증거가 된다)
- 회사별 회귀 문장 (30번 문항)
- 말하지 않을 것 목록의 회사별 항목

**형식 규칙**

- 답변은 말할 문장 그대로 쓴다. 코칭·주석은 인용구 한 줄로만.
- 답변 길이 1분 이내 기준. 30분에 15~18문항이 나간다.
- 없는 경력을 만들지 않는다. 부풀린 한 곳이 걸리면 진짜 숫자까지 의심받는다.

## 3. 표준 문항 커버리지

v3 문서의 문항 세트를 기준으로 빠진 것이 없는지 확인한다. 특히 실전에서 데였거나 준비 없이 가면 무너지는 것들:

| 문항 | 실패 방지 규칙 |
| --- | --- |
| 가고 싶은 회사/롤모델 | **기준 → 사례 1~2개 → 이 회사로 회귀** 구조. 동경 회사가 아니라 내 기준의 실물 사례를 답한다. 빅테크는 서사와 충돌 |
| 이직 사유 | 능력 문제("못 낸다")가 아니라 구조 문제("잴 수 없다")로. 전 회사 재무·내부 사정은 어떤 형태로도 말하지 않는다 |
| 회사에 얘기해봤나 (이직 사유 꼬리) | 이직 사유와 세트로 준비. ① 할 수 있는 건 했다 ② 못 한 것 인정 ③ 권한 밖 구분 |
| 연봉 | 현재 연봉을 먼저 말하지 않는다. 희망 범위(하한·상한)를 미리 정하고 들어간다 |
| 단점 | 실제 패턴에서 고른다 (예: 재미있는 문제가 필요한 문제를 이긴다). 위장 장점 금지 |
| 혼자 일했는데 팀에 맞나 | 자기 리스크 인정 + 대응책까지. 없으면 방어적으로 들린다 |
| 병역(해당 시) | 지정업체 여부·T/O·전직 절차를 확인해 "가능합니다 + 확인했습니다 + 시점" 3단으로. "알아보겠습니다"는 감점 |

## 4. 연습과 점검

- 이직 사유 → "회사에 얘기해봤나" 연결을 소리 내어 연습한다. 앞만 준비하면 불평으로 끝난다.
- 체크리스트(문서 하단)를 면접 전날 다시 본다. 외울 숫자는 5개를 넘기지 않는다.

## 5. 실전 후 복기 (이 스킬의 갱신 조건)

면접이 끝나면 그날 안에:

1. 예상 밖 질문과 막힌 답을 기록한다.
2. 막힌 문항은 v3 문서에 번호를 붙여 추가한다 (30번 "가고 싶은 회사"가 이렇게 생겼다).
3. 반복될 유형이면 **이 스킬의 3번 표에 실패 방지 규칙로 승격**한다.

문서에만 두면 다음 면접에서 또 놓친다. 규칙이 된 것만 지켜진다.
