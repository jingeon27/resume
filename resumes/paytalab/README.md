## 이번에 앞에 둔 경험

- 직접 발견한 모바일 리뷰의 세 가지 선택 불편을 PO에게 공유하고 담당자의 개선안을 구현한 과정
- 앱 뒤로 가기와 외부 이동을 나누고 WebView에서 끊기는 흐름을 배포 전에 고친 경험
- 건강검진의 동작과 예외를 개발팀장, 부팀장과 맞추고 세 제품에 반영해 출시한 경험
- 이벤트 랜딩과 SEO, 백오피스와 정산, Sentry 오류 대응을 함께 맡은 범위
- 테스트와 AI 개발 workflow의 검증 기준과 실제로 놓친 조건을 보완한 사례

기술 목록은 경력 뒤로 옮기고, 상세 설계와 검증은 공통 포트폴리오로 연결했습니다.

설계와 분석을 주도하지 않은 제품 실험은 구현과 사용자 행동 측정 역할로 적었습니다. 리뷰 개선은 Amplitude 도입 전의 직접 사용 경험입니다.

## 미리보기와 PDF

[HTML 미리보기](resume-paytalab-preview.html)는 2026년 10월 30일 최신 원문으로 다시 생성했습니다. 원문 54개 블록과 외부 링크 14개를 보존하며 4쪽의 내용과 바닥글이 겹치거나 넘치지 않는지 확인했습니다.

PDF는 사용자 요청에 따라 이번 작업에서 갱신하지 않았습니다. 기존 PDF는 이전 원문 기준이며, 저장소의 `*.pdf` 제외 규칙에 따라 로컬 파일로만 관리합니다.

저장소 루트에서 실행합니다.

```sh
node scripts/build-paytalab-preview.mjs
```

원문이나 인쇄 스타일을 수정하면 HTML을 다시 생성하고 페이지 넘침을 확인합니다. PDF를 별도로 생성할 때는 위 명령에 `--pdf`를 붙입니다. PDF 생성은 기본적으로 macOS Google Chrome을 사용하며 다른 환경은 CHROME_BIN으로 지정합니다.
