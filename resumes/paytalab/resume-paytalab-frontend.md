## 소개

React·TypeScript로 복지몰과 병원 관리자·백오피스를 함께 개발하는 프론트엔드 엔지니어입니다. 모바일 리뷰를 직접 써 보며 발견한 불편을 PO님께 공유해 개선했고, 검진 예약에서는 선택을 수정하는 상황을 짚어 담당자분과 동작을 조정했습니다. 사용자의 신청부터 병원과 운영팀의 처리 과정까지 살피며 개발합니다.

#### Sentry 도입과 운영 오류 대응 | 2026.08 – 현재

8월 19일부터 복지몰의 브라우저·서버·Edge에 Sentry를 적용해 27일 운영에 배포했습니다. release·브라우저 소스맵을 연결해 오류의 원인과 영향을 받은 사용자를 추적했습니다.

- SDK 소스를 읽고 오류 정보에서 의료·인증 정보를 제거했습니다. API 처리와 Error Boundary의 중복 수집을 막고, 차단 게이트로 의미 없는 전송을 줄였습니다.
- Bottom Sheet 드래그 크래시는 라이브러리의 null ref 접근까지 추적하고 버전업으로 해결했습니다. 배포 전 누적 **75건·57명 이상**에게 발생한 오류 그룹은 9월 10일 배포 뒤 28일까지 **18일간 0건**이었습니다.
- 회원 조회의 모든 실패가 로그아웃으로 이어지던 정책을 401일 때만 끊도록 바꿨습니다. 타임아웃·서버·네트워크 오류로 로그인 상태를 잃지 않게 했고, 9월 23일 배포 뒤 28일까지 관련 CS와 Sentry 이슈가 없음을 확인했습니다.
- 인증 후 화면 이동 중 멈추는 오류는 Next.js 라우터 소스를 읽어 `redirect()` 처리 중 훅 호출 순서가 어긋나는 경로를 찾았습니다. 진입 판정을 렌더 전 proxy로 옮겼습니다.
- 관리자 서비스의 Error Boundary는 목록·상세·오버레이처럼 따로 복구할 수 있는 단위로 나눴습니다. 일부가 실패해도 정상 구획은 유지하고 실패한 구획만 다시 시도하도록 했습니다.
