## 제출 전 확인

- 현역 산업기능요원 전직 지원 가능 여부는 아직 확인되지 않았습니다.
- 개인 프로젝트는 초기 사용자 검증 준비 단계입니다. 전환율, 재방문이나 운영 부하 성과는 적지 않았습니다.
- Terraform은 구성과 mock provider 테스트가 있는 상태를 설명합니다. 실제 AWS apply 완료로 표기하지 않았습니다.
- 게임 서비스의 4KB 내용 검사와 ETag 조건부 복사를 사진 서비스에도 적용했다고 쓰지 않습니다. 사진 서비스는 원본 직접 업로드와 HEAD 확인 정책입니다.
- Markdown 원문만 작성했습니다. PDF 제출 시 코드 링크와 표, 코드 블록의 줄바꿈을 확인해야 합니다.
