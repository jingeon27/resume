#### CSR·SSR 범위와 데이터 조회 설계 | 2025.05 – 현재

- 관리자 검색 오류는 localhost의 `dev`에서는 나타나지 않아 `build` 후 `start`로 재현했습니다. 목록 7개 중 6개에서 확인하고 업스트림 라우터 캐시 이슈까지 추적했습니다. 서버가 검색 조건을 읽지 않는 화면의 같은 경로 쿼리 변경은 History API로 처리했습니다. 수정 뒤 9월 28일까지 같은 증상의 재보고는 없었습니다.

#### AI 개발 workflow와 개발 환경 개선 | 2026.04 – 현재

compound engineering 방식으로 skills를 보강하며 에이전트에 맡기는 범위를 넓혔습니다. 구현이 의도와 어긋나면 코드만 고치지 않고 파일 배치·상태 관리·공통 코드 사용 기준을 skills나 lint rule에 남겼습니다. FSD 구조와 테스트 기준도 저장소에 맞게 다듬었습니다.

티켓·plan 검토 → 테스트 작성 → 에이전트 구현·에이전트 코드 리뷰 → 변경분 테스트·lint·typecheck → 직접 diff 리뷰·화면을 띄워 동작 확인 → 전체 CI(테스트·knip·lint) → QA 더블 체크 요청

완성본의 코드와 테스트를 읽고 부족하면 반려한 뒤 수정본을 확인합니다. 에이전트 리뷰의 critical 항목은 자동 수정하고 그 결과도 검토합니다. 단계 중 문제가 나오면 앞 단계로 돌아갑니다.

- lint rule은 RuleTester·`__fixture__`·mock으로 검증하고 Knip으로 미사용 파일·export를 검사합니다.
