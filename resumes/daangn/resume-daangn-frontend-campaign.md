- 예약 화면의 가족과 날짜 값이 Query 캐시, Zustand, 로컬 상태에 흩어져 선택한 일시가 어긋났습니다. 서버 목록은 Query, 입력값은 React Hook Form, 제출 조건은 Zod로 나눴고 예약 대상 선택 컴포넌트는 519줄에서 55줄로 줄었습니다.
