2026년 10월 30일 공식 공고를 다시 읽으려 했으나 클라우드 환경의 HTTPS 프록시가 연결 단계에서 403을 반환했습니다. 현재 초안은 기존에 확인한 캠페인 직무명과 저장소의 개발 기록을 기준으로 보강했습니다. 최신 공고의 주요 업무, 자격 요건과 우대 사항에 대한 문구별 대조는 원문 접근 후 진행해야 합니다.
