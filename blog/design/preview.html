김진건스타일 미리보기

이 페이지는 본문, 인용문, 코드 블록과 표의 가독성을 확인하기 위한 샘플입니다. 브라우저 폭을 줄이면 모바일에서의 여백과 줄바꿈도 확인할 수 있어요.

흰 배경 위에 글이 먼저 보이도록 장식을 줄였습니다. 중요한 판단은 굵기로 구분하고, 관련 내용으로 이동하는 링크는 색과 밑줄로 표시합니다. useSuspenseQuery 같은 인라인 코드도 문장 안에서 읽을 수 있습니다.

인용문 안에서도 문단을 구분합니다

테스트가 성공했다는 것과 사용자가 기대한 동작이 구현됐다는 것은 같은 말이 아닙니다.

그래서 어떤 조건을 확인했는지, 아직 무엇을 확인하지 못했는지를 함께 적습니다.

긴 코드는 블록 안에서 스크롤합니다

줄바꿈과 들여쓰기를 유지합니다. 긴 코드가 있어도 본문 전체의 폭이 늘어나지는 않습니다.

// 코드 블록의 색과 가로 스크롤을 확인하기 위한 예시
function replaceSearch(params: URLSearchParams) {
  const url = `${window.location.pathname}?${params.toString()}`;
  window.history.replaceState(null, '', url);
}

const readableOnMobile = '이처럼 긴 문자열은 코드를 강제로 접지 않고 코드 블록 안에서 가로로 스크롤해 확인합니다.';

본문과 보충 설명의 무게를 다르게 둡니다

확인한 것

화면 크기에 따른 제목 줄바꿈, 본문 읽기 폭, 인용문 문단 간격과 코드 블록의 대비를 확인합니다.

선택한 방식

본문은 한 열로 읽고, 소제목과 여백으로 내용의 전환을 표시합니다.

적용 전 확인

공개 블로그에는 CSS 전체를 직접 교체해야 합니다. 기존 스킨 CSS를 백업한 뒤 적용하세요.
