동기화 훅은 폼 배열과 서버 목록의 길이를 비교해 할 일을 고르고, 누구를 남기고 붙일지는 memberId로 정해요. 추가·삭제 예는 7월 2일 10:30을 고른 뒤의 상황이에요. ✓는 선택된 사람이에요.

배열을 건드리지 않아요. 선택 여부와 희망 일시는 동기화 훅이 아니라 체크박스·날짜 핸들러·사람별 시트가 폼에서 직접 바꿔요.

새 칸을 만드는 함수
initParticipant(덮어쓸 값)(서버 값) => ({
  ...서버 값,            // memberId · name · 기본 선택
  preferredDate, preferredTime, // 폼의 공통 일시
  ...덮어쓸 값,          // 추가일 때 selected: true
})
처음 채우기와 추가가 이 함수로 칸을 만들어요. 날짜 핸들러도 같은 함수에 새 일시를 덮어쓸 값으로 넘겨 모든 칸의 일시를 바꿔요.
건너뛰는 때
회원 정보가 아직 없으면 서버 목록이 null이라 아무것도 하지 않아요. 서버 목록은 본인을 맨 앞에 두고 가족을 이어 붙여 계산해요.

실제 코드(가족 동기화 훅, 예약 대상 목록 계산 훅, 가족 인증 시트, 가족 삭제 훅)를 바탕으로 그렸어요. 코드는 줄였고, 코드 이름은 글과 같은 가명이에요.
