필드 이름과 값의 타입을 함께 연결해요

필드 이름을 enum으로 모으던 방식에서, 폼 타입으로 접근 경로와 값을 제한하는 방식으로 옮겼어요.

공유 패키지
공통IProgramFormCommon → ProgramForm
interface IProgramFormCommon {
  programName: string;
  price: number;
  treatmentSubId: number;
  // 공통 입력 · 이미지 · 템플릿 · 검진 구성
}
const ProgramForm = createTypedForm<IProgramFormCommon>();
공통 타입에 앱 전용 필드를 더해요 ↓
Back-Office
interface IProgramInspectionClient
  extends IProgramFormCommon {
  memo?: string;
  rejectReason?: string;
  hidePrice?: boolean | null;
  // 운영·검수 전용 값
}

운영 설정과 승인·반려에 필요한 값을 다뤄요.

병원 관리자
interface IProgramInspectionClient
  extends IProgramFormCommon {
  adminId: number;
  adminName: string;
  programId?: number;
  inspectionType: InspectionType;
}

등록·수정·삭제 검수 요청의 정보를 다뤄요. InspectionType은 설명용으로 줄인 이름이에요.

같은 factory, 앱마다 필요한 타입
TFieldNamePath<T>

keyof와 중첩 경로로 Item·List·watch·get/set의 필드 이름을 제한해요.

TPathValue<T, P>

조건부 타입과 infer로 경로를 따라가 get의 반환값과 set의 입력값을 연결해요.

ProgramForm.useFormInstance() 
form.getFieldValue('programName');       // string
form.setFieldValue('price', 100000);     // 허용
form.getFieldValue('programNmae');       // 없는 필드
form.setFieldValue('price', '100000');   // 값 타입 불일치
실제 폼 인스턴스는 하나예요. 공통·앱 전용 typed API는 같은 Ant Design Form 컨텍스트를 사용해요. 입력을 공유해도 요청 처리까지 공유하지는 않아요.

현재 프로그램 폼 타입과 createTypedForm 구현을 바탕으로 그렸어요. 일부 필드와 타입 이름은 줄였어요.
