런타임에는 폼이 하나다. 앱 컨테이너가 ProgramInspectionForm.useForm() 으로 만든 인스턴스를 공유 FormItem 은 ProgramForm.useFormInstance() 로 받아, 공통 필드만 보이는 타입으로 쓴다. 앱 전용 필드와 제출 흐름은 패키지로 올라가지 않는다. 이 typed form 은 그림 1의 검수 폼 화면 파일과 이름만 같고, 상세 폼 컨테이너도 이것으로 인스턴스를 만든다.
좁혀지지 않는 곳
  • 중첩 경로의 값 타입. 경로 중간의 배열이 optional 이거나 null 을 허용하면 TPathValue 가 never 가 되는데, 이 폼의 배열 필드는 모두 그렇다. 목록 항목 값은 antd useWatch·getFieldValue 로 읽는다.
  • Form.List 안의 상대 경로(name={[field.name, 'title']})는 루트 타입으로 표현되지 않아 antd Form.Item 을 그대로 쓴다. 하위 시술 템플릿 편집 폼과 같이 쓰는 템플릿 입력(추천 대상 등)도 antd Form 과 이름 상수로 남아 있다.
  • 빈 경로([], '')는 표현하지 않아, 폼 전체를 읽는 미리보기와 정가·우대가 교차 검증은 antd 를 그대로 쓴다.
  • antd 와 잇는 단언 as unknown as 는 createTypedForm 안에만 있고, 프로그램 폼 래퍼에 앱마다 props as FormProps 가 하나씩 남았다.
