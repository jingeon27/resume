## 8. 증거 수준

각 성과 문장에 가장 가까운 수준을 표시한다.

| 수준 | 의미 | 예시 |
| --- | --- | --- |
| A | 배포 후 수치로 확인 | 빌드 시간 4분에서 1분으로 단축 |
| B | 로그·테스트·운영 기록으로 확인 | 배포 후 7일 동안 회귀 장애 0건 |
| C | 운영자·사용자 피드백으로 확인 | 정산 담당자가 엑셀 작업이 사라졌다고 확인 |
| D | 코드 변경으로만 확인 | 오류 경계를 화면 전체에서 구획 단위로 분리 |

## 작성 전 확인 사항

- [ ] PRD의 목표와 실제 결과를 구분했다.
- [ ] 팀 전체의 성과를 개인 성과로 표현하지 않았다.
- [ ] 직접 측정하지 않은 수치를 만들지 않았다.
- [ ] 평균·최댓값 대신 비교 조건과 중앙값을 함께 확인했다.
- [ ] 측정 기간과 분모를 적었다.
- [ ] 파일 수와 커밋 수를 사용자 성과처럼 표현하지 않았다.
- [ ] 배포 후 회귀 장애와 남은 제약을 함께 기록했다.
- [ ] 회사 상황처럼 개인이 통제할 수 없는 결과를 분리했다.
- [ ] 공개하면 안 되는 회사·사용자·인증 정보를 제거했다.
